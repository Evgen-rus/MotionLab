## 30. Cube-Grid Ripple

**Результат:** Волна сетки кубов. **Когда:** объёмный фон.

**Пример MotionLab:** Объёмный фон в авторской HTML-сцене; вычислить следующий рецепт внутри `seek(t)`, привязав `dt=t-start` к началу элемента.

**Алгоритм / JS-псевдокод:**

```js
InstancedMesh 24x24; z=sum(kicks.filter(k<=t).map(k=>A*exp(-8*(r-speed*(t-k))**2)*exp(-(t-k)))); updateMatrix каждого экземпляра, needsUpdate=true
```

**Параметры и тайминг источника:** An InstancedMesh cube field (about 576 instances). Each kick spawns a radial ring that pushes the cubes in Z.

**Совместимость и зависимости:** Локальный Three.js (не установлен библиотекой), WebGL; для текста TextGeometry + FontLoader и локальный лицензированный font JSON. Доступность проверить перед применением. Все состояния вычислять из t; значения кадра источника делить на 60, а не на fps экспорта. Для 3D вручную вызвать renderer.render(scene,camera) в seek.
