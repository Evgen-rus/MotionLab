## Как использовать

«Используй Letter Rise Stagger для появления текста». «Предложи три варианта динамичной анимации заголовка из библиотеки». «Подбери необычный переход между этими сценами». «Сделай обычную спокойную анимацию, без дополнительных эффектов».

В каждом рецепте есть результат, назначение, пример, алгоритм и тайминг. Указанный пример — сценарий применения, а псевдокод требует привязки к элементам конкретной сцены. Исполняемые демонстрации есть только для пяти приёмов ниже. Scenario MCP, API и аккаунт не нужны.

## Общая математика и контракт

`W,H` — размеры кадра; `dt=t-start`, `p=clamp(dt/duration)`, `beat=60/BPM`, `bar=beat*beatsPerBar`. BPM и списки ударов берутся из брифа/подготовленного тайминга, не угадываются. `lastIndex` возвращает -1 до первого события: в этом случае показывать исходное состояние. `hash(i,frame)` — чистый целочисленный хеш с фиксированным seed, никогда Math.random. Движение не зависит от fps: `fr` исходника всегда = 1/60 секунды.

```js
const clamp=x=>Math.max(0,Math.min(1,x));
const lerp=(a,b,p)=>a+(b-a)*p;
const out3=p=>1-(1-p)**3, out4=p=>1-(1-p)**4;
const out5=p=>1-(1-p)**5, in4=p=>p**4;
const expo=p=>p===1?1:1-2**(-10*p);
const inExpo=p=>p===0?0:2**(10*(p-1));
const inOut3=p=>p<.5?4*p**3:1-(-2*p+2)**3/2;
const inOut4=p=>p<.5?8*p**4:1-(-2*p+2)**4/2;
const inOutExpo=p=>p===0||p===1?p:p<.5?2**(20*p-10)/2:(2-2**(-20*p+10))/2;
const outBack=(p,s=1.70158)=>1+(s+1)*(p-1)**3+s*(p-1)**2;
function spring(dt,k,z) {
 if(dt<=0)return 0; const w=Math.sqrt(k),d=w*Math.sqrt(1-z*z);
 return 1-Math.exp(-z*w*dt)*(Math.cos(d*dt)+z*w/d*Math.sin(d*dt));
} // mass=1, 0<z<1; при завершении сцены явно фиксировать цель
const hash=(i,f)=>{let x=(i*374761393+f*668265263)|0;x=Math.imul(x^(x>>>13),1274126177);return (x^(x>>>16))>>>0;};
```

Каждый seek сначала сбрасывает transform, alpha, clip и фон, затем вычисляет весь кадр. Для эха повторно вычислять состояние на t-delay. Никаких таймеров, накопления физики или истории кадров. На отрицательном локальном времени показывать начальную позу; после конца — конечную. Элементы размечать стабильными data-element-id и временными интервалами для Workbench. Для видео-декора перед захватом дождаться seeked и декодирования кадра.

3D-рецепты 30–36 описаны для локального Three.js, который не устанавливается автоматически. Проверить WebGL в текущем headless-браузере; использовать локальные модули, шрифты и текстуры. Vortex/Droste/Orbit можно приблизить Canvas/SVG, но это не равнозначно проверенной реализации 3D. Для полноценного Variable-Width Wave требуется шрифт с wdth; для Weight Ladder 100–900 — соответствующий диапазон веса.

## Исполняемые демонстрации

[demos/landscape.html](demos/landscape.html) (960×540) и [demos/portrait.html](demos/portrait.html) (540×960) используют один [demo.js](demos/demo.js), локальный Manrope 800 и его OFL. Пять последовательных двухсекундных фрагментов: Letter Rise Stagger, Smear Slam, Punctuation Portal, Spring Morph + Ghost Outlines, Whip Pan with Smear Frame. Spring Morph — 128 точек и 4 пересчитанных следа; это упрощённая демонстрация без спутников. Smear Slam демонстрирует масштаб, три следа и короткую вспышку. Короткие приёмы намеренно не растянуты на длительность фрагмента.

Статическая HTML не запускает таймер: вызвать `await window.__video.seek(t)` или использовать штатный preview/render. Просмотр кадров: `node .agents/skills/motionlab/scripts/render.mjs --in motion-design-library/demos/landscape.html --out "projects/Библиотека приёмов/кадры-01" --stills 0.1,2.05,4.08,6.2,8.09`. Каждый out должен быть новым. Для portrait заменить вход и каталог. Полный MP4 авторского ролика требует обычного согласования; демо не даёт разрешения на экспорт пользовательских проектов.
