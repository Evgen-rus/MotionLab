# Deep intake: from references to a director's brief

Read only when the user selects «Глубокий разбор» for a new video brief, or asks to deepen an existing brief. Use the shared intake requirements in visual-first.md; this guide develops the concept before the existing design-option stage. The outcome is a coherent, actionable brief, not a completed questionnaire.

## Conduct the conversation

- Start with what the supplied idea and inspected references already establish, what is uncertain, and which decisions matter next. Do not claim to have inspected inaccessible media.
- Ask 2–3 related questions per round, with concrete task-specific options and a recommendation explaining its effect on the viewer. Use the available question tool as described in visual-first.md; support free text and «помоги выбрать». For media that must be reattached, ask directly in chat instead of using a text-only question tool.
- After each block, briefly state the decisions reached and adapt the next questions. Skip resolved or irrelevant topics; use the question map below selectively, not as a fixed sequence or a form to send all at once.
- Offer stronger approaches when justified by the goal, audience, reference evidence or available material. Explain the benefit and compromise without presenting personal taste as fact. Preserve fixed requirements; get the user's choice before materially changing the concept, message or scope.
- Distinguish user decisions, delegated creative choices, proposals awaiting a choice, and facts still needing evidence. Delegation allows creative recommendations, not invented product facts or a silently inferred audience.
- Let the user switch to ordinary intake or delegate unresolved creative choices at any point. Resolve required brief answers and production blockers without forcing the remaining deep questions. Silence is not a choice.

## Question map

Each question should change a content, staging, timing or delivery decision. Tailor examples to the actual piece; an abstract title sequence does not need a sales story or a protagonist.

| Topic | Decisions to establish | Useful prompts |
|---|---|---|
| Purpose | Desired understanding, feeling or action | What should change after viewing? Which outcome takes priority? |
| Viewer and context | Explicit audience, familiarity, viewing conditions | First encounter or existing users? Scrolling without sound, website, presentation? What makes this relevant to them? |
| Main message | One takeaway, essential content, omissions | If they remember one thing, what is it? What can we remove without losing the point? |
| Evidence | Available demonstrations and supported claims | Can we show the real interface, an example, a result or verified figures? What cannot be claimed or shown? |
| Opening | First image and reason to keep watching | Reveal the result, pose a relevant question, show a recognizable situation or use a visual contrast? Why does that fit this viewer? |
| Development and ending | Meaningful sequence, reveal, payoff, CTA or none | Process, before/after, one use case or a short story? What changes between opening and ending? Is the ending a conclusion, an action or a loop? |
| References | Roles, fidelity and exclusions | Which source guides motion, layout, typography or mood? What should not transfer? Which reference wins when they conflict? |
| Visual character | Desired feeling, boundaries, brand assets | Calm and precise, warm, playful or energetic? What would feel cheap, generic, overly busy or off-brand? |
| Motion and pace | Attention, reading pauses, meaningful movement | Smooth development or sharp cuts? Where must viewers have time to understand? Does movement explain something or set the mood? |
| Text and sound | Allocation across image, text, narration, music and effects | What should be shown rather than said? Must it work silently? Does music lead the pacing or support it? |
| Delivery and constraints | Shared intake settings plus real production limits | Platform and placement, duration, size, variants, required assets, deadline or size limit if relevant? Any material we still need? |
| Acceptance | Priorities, fixed requirements, creative freedom | Which 2–3 qualities define success? What would spoil the result? Which wording/assets are fixed, and where may I propose alternatives? |

## Select a concept before styling when needed

If the narrative approach is unresolved, offer 2–3 short, materially different concept pitches using the actual brief. For each, describe the opening, development, ending and its main trade-off; recommend one. For example, showing the result first, following one use case, or contrasting before/after can serve different goals. Do not mechanically use these examples for every task.

Let the user select, combine, revise or explicitly delegate. Skip this choice when the concept is already clear. Concept pitches do not replace the three rendered visual directions or approve an unseen storyboard; do not produce extra mockups or full videos for this conversation.

## Check the concept and close intake

Before moving to visual directions:

1. Name the concrete weak points that affect this piece and propose fixes: too much copy for its duration, an unclear opening, missing evidence, contradictory reference roles, unavailable assets or an infeasible effect. Resolve blockers or obtain a choice of a feasible alternative; label optional uncertainties for later visual/audio trials.
2. Retell it in plain Russian: «Сначала зритель увидит …, затем поймёт …, в конце …». If the causal sequence or payoff is unclear, improve it with the user before styling. Judge interest against the agreed viewer and purpose, not a promise of popularity.
3. Present a concise director's brief containing:
   - Goal, explicit audience, viewing context, main takeaway and supported evidence.
   - Selected concept, opening, sequence of semantic beats, ending and CTA or none.
   - Visual character, reference roles, intended motion/pace, and the division between image, text and sound.
   - Agreed delivery settings and constraints, fixed requirements, creative freedom and 2–3 acceptance criteria.
   - Delegated choices, proposals still unresolved, missing materials and limitations, if any.

Invite corrections and ask only for unresolved decisions; do not add a mandatory approval gate for an already resolved brief. Save the selected intake depth and director's brief in job.decisions, with agreed values in job.brief. Preserve enough context to resume without repeating the interview; use the existing job structure, not a new questionnaire file or schema.

Proceed to the existing three visual options, then storyboard and final production confirmation. Carry the brief's priorities and acceptance criteria into that review; revisit only decisions affected by later changes. Deep intake does not authorize rendering or substitute for the required visual and audio previews.
