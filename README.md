# MotionLab

Откройте чат AI-агента в этой папке, приложите видео, изображение или несколько файлов и напишите:

> Используй $motionlab из .agents/skills/motionlab. Разбери движение в этом видео и сделай мой ролик с текстом «…». Сначала задай вопросы и покажи варианты оформления. После моего одобрения создай анимацию и готовый MP4.

Агент анализирует роли материалов (например, движение из видео и шрифты со скриншота), уточняет только недостающие параметры и показывает настоящий PNG-лист A/B/C. Затем согласует типографику, сториборд и звук, если он нужен. Можно смешивать варианты или просить ещё три. Агент всё делает сам. Вам нужно выбрать понравившийся вариант и сказать, что изменить. Для сохранения разбора без создания ролика добавьте: «Пока только сохрани референс».

Чтобы использовать в другом проекте, попросите агента скопировать туда папку `.agents/skills/motionlab` из этого репозитория и следовать её `SKILL.md`. Подготовкой окружения занимается агент.

Имя skill для вызова: `$motionlab`; в списке он отображается как **MotionLab**. После переименования откройте новый чат в этом проекте, чтобы обновился список skills.

Происхождение и лицензии компонентов указаны в [NOTICE.md](.agents/skills/motionlab/NOTICE.md).

Для каждого ролика агент спрашивает рабочее название (предпочтительно на русском) и складывает все материалы в `projects/<название>/`. Внутри — `job.json`, исходники, версии сцены, превью и готовые MP4. Для доработки в новом чате укажите эту папку: агент прочитает состояние и создаст следующую версию, сохранив предыдущую. Материалы для повторного рендера остаются после выдачи MP4; очистка выполняется только по запросу. Чтобы удалить ненужный ролик целиком, достаточно удалить его папку (вместе с исходниками и версиями).

## Workbench — ручной монтаж и команды в чате

### Озвучка через OpenRouter

В корневом `.env` задайте `OPENROUTER_API_KEY`, `OWNER_VOICE_ENABLED=true` и `OPENROUTER_TTS_VOICE` (пример: `cb92b10e1a5946b9b6bd7391aefe31fe`). Остальные настройки перечислены в `.env.example`: модель по умолчанию `fish-audio/s2.1-pro-free:free`, таймаут 120 секунд, лимит стоимости 0 USD. Ключ хранится только локально.

Попросите агента озвучить утверждённый текст ролика. Агент сначала покажет текст, затем выдаст MP3 и подключит его к рендеру через `--audio`. Команда для UTF-8 сценария:

```bash
node --env-file-if-exists=.env .agents/skills/motionlab/scripts/speech.mjs --in "projects/Название ролика/диктор.txt" --out "projects/Название ролика/озвучка-01"
```

Папка результата должна быть новой. При сбое текст остаётся в `text.txt`; успешная озвучка — `voice.mp3`. Неизвестная цена и платные модели блокируются; положительный лимит пока не разрешает модели с неопределимой стоимостью выхода. В Workbench отдельная дорожка озвучки пока отсутствует.

Дополнительный локальный видеоредактор открывается в браузере. Он использует существующий FFmpeg, не требует React/Remotion или отдельного видеодвижка. Из папки проекта запустите:

```bash
node .agents/skills/motionlab/scripts/workbench.mjs --project "Название ролика"
```

Откройте локальный адрес, выведенный командой. В редакторе есть импорт нескольких видео, большой просмотр, шкала времени с перестановкой фрагментов, разрезание и точная обрезка, отключение звука отдельного клипа, форматы 16:9/9:16/1:1/1080p и экспорт MP4 со звуком. Исходники не изменяются. При экспорте создаётся новая папка `projects/<название>/монтаж/экспорт-NNN/`; состояние монтажа хранится в `edit.json` рядом с `job.json`.

Codex может управлять этим же монтажом из разговора — например, по просьбе «Импортируй видео и обрежь первый клип с 2 до 5 секунд» выполнить:

```bash
node .agents/skills/motionlab/scripts/workbench.mjs --project "Название ролика" --import "C:/Видео/клип.mp4"
node .agents/skills/motionlab/scripts/workbench.mjs --project "Название ролика" --command "Обрежь клип 1 с 2 до 5"
node .agents/skills/motionlab/scripts/workbench.mjs --project "Название ролика" --export yes
```

Для произвольного монтажа Codex может передать структурированную операцию через `--action '{"type":"split","index":1,"at":3}'`. Действия: `append`, `trim`, `split`, `remove`, `move`, `mute`, `format`; нумерация клипов начинается с 1. Встроенная строка команд понимает ограниченный набор русских команд, а сложные творческие правки по-прежнему выполняет агент в разговоре. Монтаж клипов и создание новых HTML-анимаций — разные процессы: согласование дизайна/сториборда для новых сцен сохраняется.

### Работа в редакторе

Попросите агента: «Открой Workbench проекта “Название ролика”». В существующем проекте загрузится сохранённый монтаж. Сервер должен оставаться запущенным во время работы и экспорта; закрытие вкладки не удаляет монтаж. При повторном открытии проекта используются прежние `edit.json`, исходники и экспорты.

- Добавьте видео кнопкой **+** рядом с «Исходники» или кнопкой импорта в пустом проекте. При импорте копия видео сохраняется в проекте и добавляется на таймлайн. Кнопка **+** у исходника добавляет ещё один его фрагмент.
- Выберите фрагмент на таймлайне. Справа задайте начало и конец **относительно исходного видео**, затем нажмите «Применить границы». Там же можно отключить звук, поменять позицию или удалить фрагмент; исходный файл остаётся в библиотеке.
- Нажмите на линейку времени и «Разделить». Перетаскивание фрагментов меняет порядок. «Раньше» и «Позже» выполняют ту же задачу без перетаскивания.
- **Пробел** запускает и останавливает просмотр, **← / →** вне полей ввода перемещают курсор на кадр. **Delete** удаляет выбранный фрагмент. Клип можно выбрать клавишей **Tab**, затем **Enter**.
- Выберите формат экспорта. Рамка просмотра показывает пропорции будущего ролика; изображение сохраняется целиком с полями. **Экспорт MP4** создаёт новый файл; ссылка появляется в «Готовые экспорты».

Для строки команд используйте точные короткие фразы: «Обрежь клип 1 с 2 до 5», «Раздели клип 1 на 3», «Перемести клип 2 на позицию 1», «Убери звук у клипа 1», «Формат 9:16». Составные задачи, анализ референсов и творческие просьбы отправляйте Codex в чат. Строка в редакторе сама не вызывает модель. Изменения агента через CLI автоматически появляются в открытом редакторе.

Текущая версия монтирует одну последовательность видеофрагментов с их звуком. Независимые аудио/видеодорожки, цветокоррекция, шумоподавление и субтитры пока не реализованы. Некоторые MOV/MKV кодеки могут не воспроизводиться в браузере, даже когда FFmpeg умеет их экспортировать. Лимиты: 1 ГБ на файл, 200 исходников, 60 фрагментов и до 60 минут итогового монтажа.

### Дизайн интерфейса

Локально установлен `$impeccable`; продуктовый контекст хранится в `PRODUCT.md`. Рабочие файлы Workbench — `.agents/skills/motionlab/scripts/workbench-ui/`. Для развития интерфейса выбран процесс «сначала макет картинкой». Дизайн рассчитан на веб-приложение в Chrome, без имитации кнопок окна macOS. Шрифт Manrope и его лицензия находятся внутри skill; внешние CDN, шрифтовые сервисы и UI-фреймворки для работы редактора не требуются.

Пользовательские референсы, дизайн-макеты, снимки проверки, локальное состояние Impeccable, проекты и медиа не отправляются в Git. Для проверки инструментов: `npm ci --ignore-scripts --prefix .agents/skills/motionlab/scripts`, затем `node --test tests/*.test.mjs` из корня проекта.

### Библиотека приёмов моушен-дизайна (необязательно)

В [motion-design-library/](motion-design-library/README.md) доступны 40 рецептов: анимация букв и слов, геометрические формы, 2D/3D-эффекты, движения камеры и переходы. Это дополнительный справочник для агента; обычный процесс MotionLab сохраняется, библиотеку можно полностью игнорировать. Отдельный API, Scenario MCP или аккаунт не нужны. Для семи 3D-рецептов описан локальный Three.js; он автоматически не устанавливается. Пять приёмов имеют исполняемые локальные демосцены, остальные представлены рецептами.

Примеры запросов:

- «Предложи три варианта динамичной анимации заголовка из библиотеки».
- «Используй Letter Rise Stagger для появления текста».
- «Подбери необычный переход между этими сценами».
- «Сделай обычную спокойную анимацию, без дополнительных эффектов».

Полный каталог, алгоритмы, зависимости и примеры — в [README библиотеки](motion-design-library/README.md).
