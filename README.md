# MotionLab: локальные видео и анимации

Основа: NiazMorshed2007/reanimate, MIT, снимок commit 522a353be364828ef43e1440faf5c1077edccbc1. Исходный снимок не изменён. Адаптированы подход и извлечение кадров; листы переписаны на ffmpeg без браузера. Скилл находится только в .agents/skills/reanimate.

Откройте PowerShell в D:\My_dev_project\MotionLab:

```powershell
& .\.agents\skills\reanimate\scripts\setup.ps1
node .agents/skills/reanimate/scripts/frames.mjs --in "D:\Videos\пример.mp4" --out .reanimate/ref-01 --start 0 --end 5 --fps 10 --width 800
node .agents/skills/reanimate/scripts/sheet.mjs --frames .reanimate/ref-01 --out .reanimate/sheets-01
```

Откройте PNG в .reanimate/sheets-01. Имена каталогов для каждого запуска должны быть новыми: ref-02, sheets-02 и т.д. Существующие каталоги отвергаются целиком, даже пустые. После ошибки результаты сохраняются. Выходы разрешены только непосредственно внутри .reanimate; ссылки вместо корня/кадров запрещены. Не изменяйте выходной каталог параллельно работающему процессу.

Если ffmpeg не в PATH: `$env:REANIMATE_FFMPEG = 'C:\ffmpeg\bin\ffmpeg.exe'`. Подготовка ничего не скачивает. Требуются Node.js 22+ и ffmpeg с drawtext/tile. По умолчанию извлекаются первые 10 секунд, не более 600 кадров шириной 800; пределы: 120 секунд, 1200 кадров, ширина 1920. Можно задать --max-frames. Слишком большой входной кадр может требовать значительной памяти при декодировании.

В новом чате этого проекта попросите: «Используй $reanimate. Видео D:\Videos\пример.mp4, участок 2–6 секунд. Разбери движение карточек и сделай вариант с моим текстом и цветами …». Если скилл ещё не обнаружен, откройте новый чат или укажите .agents/skills/reanimate/SKILL.md явно.

Видео даёт оценку движения, а не исходные параметры анимации. При 10 fps точность измерения порядка 100 мс; для быстрых движений используйте 25–30 fps. Для проверки результата дайте локальную запись своего варианта. Сайты, GPU-трассировка и автоматическая запись варианта в этой версии отсутствуют.

Проверки: `node --test tests/reanimate.test.mjs`. Артефакты исключены через .gitignore. Входное видео и исходный снимок не перезаписываются.
