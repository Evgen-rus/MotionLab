# MotionLab

Карта проекта для агента. Агент ведёт бриф, задаёт уточняющие вопросы, показывает варианты и получает согласования; техническую работу выполняет сам. Человек сообщает задачу, отвечает на вопросы и оценивает результат.

Новый чат в этой папке начинает с [AGENTS.md](AGENTS.md). При продолжении ролика сначала прочитай его `projects/<название>/job.json` и сохрани уже принятые решения.

- [MotionLab](.agents/skills/motionlab/SKILL.md) — основной пайплайн, вопросы, визуальные варианты, раскадровка, согласования и выдача MP4.
- [Инструменты MotionLab](.agents/skills/motionlab/references/tools.md) — локальные команды анализа, превью, рендера, Workbench, транскрибации и озвучки.
- [Музыка и эффекты](.agents/skills/music-production/SKILL.md) — оригинальная музыка, синтетические переходы и WAV.
- [Установка аудио и инструментов](.agents/skills/music-production/references/setup.md) — подготовка отсутствующего окружения по закреплённым зависимостям. Существующее рабочее окружение сохраняй.
- [Библиотека движения](motion-design-library/README.md) — необязательные рецепты приёмов для агента.
- [PRODUCT.md](PRODUCT.md) и [DESIGN.md](DESIGN.md) — продуктовый и визуальный контекст Workbench.
- [Происхождение компонентов](.agents/skills/motionlab/NOTICE.md) и [лицензии аудио](.agents/skills/music-production/references/sources-and-rights.md) — условия использования зависимостей.

Проекты, исходники, сцены, согласования, звук и готовые ролики хранятся локально в `projects/<название>/`. Ключи — в локальном `.env` по `.env.example`; рабочая конфигурация аудио — `.agents/skills/music-production/local-config.json`. Не публикуй ключи и пользовательские материалы.
