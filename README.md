# MotionLab

Откройте чат AI-агента в этой папке, приложите видео и напишите:

> Используй $motionlab из .agents/skills/motionlab. Разбери движение в этом видео и сделай мой ролик с текстом «…». Сначала задай вопросы и покажи варианты оформления. После моего одобрения создай анимацию и готовый MP4.

Агент всё делает сам. Вам нужно выбрать понравившийся вариант и сказать, что изменить. Для сохранения разбора без создания ролика добавьте: «Пока только сохрани референс».

Чтобы использовать в другом проекте, попросите агента скопировать туда папку `.agents/skills/motionlab` из этого репозитория и следовать её `SKILL.md`. Подготовкой окружения занимается агент.

Имя skill для вызова: `$motionlab`; в списке он отображается как **MotionLab**. После переименования откройте новый чат в этом проекте, чтобы обновился список skills.

Происхождение и лицензии компонентов указаны в [NOTICE.md](.agents/skills/motionlab/NOTICE.md).
