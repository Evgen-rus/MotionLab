# MotionLab

Откройте чат AI-агента в этой папке, приложите видео и напишите:

> Используй скилл reanimate из .agents/skills/reanimate. Разбери движение в этом видео и сделай мой ролик с текстом «…». Сначала задай вопросы и покажи варианты оформления. После моего одобрения создай анимацию и готовый MP4.

Агент всё делает сам. Вам нужно выбрать понравившийся вариант и сказать, что изменить. Для сохранения разбора без создания ролика добавьте: «Пока только сохрани референс».

Чтобы использовать в другом проекте, попросите агента скопировать туда папку `.agents/skills/reanimate` из этого репозитория и следовать её `SKILL.md`. Подготовкой окружения занимается агент.
