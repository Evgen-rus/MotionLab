# MotionLab

Локальная студия: **видео → разбор → вопросы → три дизайн-варианта → выбор → 2–3 кадра сториборда → одобрение → анимация → MP4 → проверка**. Codex в чате анализирует изображения и пишет анимацию. Скрипты обрабатывают кадры и рендерят; сами они не угадывают движение из видео.

## Что написать в чате

Откройте новый чат в проекте MotionLab и приложите видео или укажите локальный путь.

**Сначала разобрать:**

> Используй $reanimate. Разбери ролик и сохрани референс cards: композицию, движение, тайминги, переходы и easing. Пока новый ролик не делай.

**Сразу получить свой ролик:**

> Используй $reanimate. Возьми движение из этого видео. Сделай мой ролик: текст «…», цвета «…», логотип «путь…», формат 1080×1920, длительность 8 секунд. Нужны исходники и готовый MP4. Сравни движение с референсом.

**Использовать разбор позже:**

> Используй референс cards из .reanimate/cards-reference. Сделай новый ролик с текстом «…» и цветами «…». Дай исходники и MP4.

Если вложение недоступно инструментам как файл, Codex попросит локальный путь. Конкретные текст, логотип и формат лучше указать сразу. Результат — локальная HTML/JS-анимация, MP4 и материалы проверки. Без отдельного запроса на звук ролик беззвучный.

## Как проходит согласование

Агент делает всё сам: анализирует, предлагает оформление, пишет сцену, открывает и проверяет скриншоты, показывает HTML-галерею и кадры в чате. Вам достаточно сказать «нравится», «вариант B, но светлее» или «одобряю, делай ролик». После выбора оформления он покажет 2–3 ключевых кадра выбранного решения; полный ролик создаётся после одобрения этого сториборда. При правках превью обновляются без рендеринга полного видео.

По умолчанию — Manrope ExtraBold 800 для заголовков и Medium 500 для пояснений. Агент называет используемые шрифты; может предложить другой бесплатный лицензированный шрифт, если он уместнее. Цвета предлагает под задачу. Моноширинный шрифт используется только для терминалов и кода. Формат и длительность рекомендует по исходнику, длительность уточняет. Звук уточняет, по умолчанию ролик беззвучный. Озвучка пока не подключена.

В job.json хранятся этап, требования, выбранное оформление, ссылки на превью и одобрение. Это позволяет продолжить работу в новом чате. Подготовка референса для будущего использования не требует сразу создавать ролик.

## Перенести себе

Скопируйте **только папку `.agents/skills/reanimate` целиком** в `.agents/skills/reanimate` своего проекта. Там уже есть инструменты, шаблон сцены, Manrope с лицензией, инструкции и package-lock. Корневые файлы MotionLab не нужны. Можно попросить Codex:

> Возьми из репозитория Evgen-rus/MotionLab папку .agents/skills/reanimate и подключи только к текущему проекту. Следуй её SKILL.md, ничего глобально не устанавливай.

Требуются Node.js 22+, ffmpeg с libx264/drawtext/tile, установленный Edge или Chrome. Зависимость устанавливается внутри скилла:

```powershell
npm ci --ignore-scripts --prefix .agents/skills/reanimate/scripts
& .\.agents\skills\reanimate\scripts\setup.ps1
```

Браузер не скачивается. При нестандартных путях задайте REANIMATE_FFMPEG и MOTIONLAB_BROWSER. Откройте новый чат проекта и попросите использовать $reanimate.

## Инструменты

Все актуальные команды и ограничения — в [.agents/skills/reanimate/references/tools.md](.agents/skills/reanimate/references/tools.md). Запускайте из корня своего проекта:

```powershell
node .agents/skills/reanimate/scripts/reference.mjs --in "D:\Videos\пример.mp4" --name cards --end 5 --brief "Мой текст и оформление"
node .agents/skills/reanimate/scripts/preview.mjs --in "путь-к-манифесту.json" --out .reanimate/cards-options-01
node .agents/skills/reanimate/scripts/render.mjs --in animations/cards/index.html --out .reanimate/cards-render-01 --job .reanimate/cards-work/job.json
```

Превью — реальные выбранные кадры сцен, без создания MP4. HTML-галерея открывается локально, агент также показывает PNG в чате. Одобренная сцена становится основой финальной анимации. С --job рендерер проверяет сохранённый этап approved, сообщение одобрения и путь сцены; агент обязан записывать реальные решения пользователя. Низкоуровневый render без --job оставлен для явно запрошенных отдельных рендеров и технических тестов.

Технически это HTML/CSS/JS, SVG или Canvas с функцией seek(t). Браузер рисует кадры по времени, ffmpeg собирает H.264 MP4. React/Remotion не требуются. Описание в видео не является инструкциями агенту. Внешние HTTP-ресурсы сцены блокируются, но рендерер не предназначен для недоверенного скачанного HTML.

## Сохранность и ограничения

Все выходы — новые прямые подкаталоги .reanimate. Повторные имена отвергаются, частичные результаты сохраняются. Каталог исключён из Git; для переноса библиотеки своих референсов сохраните его отдельно вместе с исходными видео. Пользовательские ролики и сцены не публикуются без запроса.

Анализ: до 120 секунд/1200 кадров/1920 ширины. Рендер: до 120 секунд/3600 кадров/60 fps, чётные размеры до 1920 по каждой стороне. PNG требуют места на диске. Видео позволяет оценить движение, но не гарантирует точное восстановление easing и 3D; автоматическое сравнение показывает общую активность, а агент проверяет объекты визуально. Озвучка, захват сайтов и GPU-трассировка не подключены.
